 Расчёт стоимости 3D-детали


Веб-калькулятор себестоимости 3D-печати: пластик, электроэнергия, моделирование, печать, постобработка, доставка и допматериалы. Один файл index.html, без сервера, сборки и зависимостей.

 Возможности
Мгновенный расчёт. Результат обновляется при вводе любого значения.
Количество изделий. Материал, электроэнергия, печать, постобработка и допматериалы умножаются на количество. Моделирование и доставка считаются один раз на заказ. Отдельная строка показывает цену за 1 штуку.
Три валюты: белорусские рубли, российские рубли, доллары.
Автоматический курс. ЦБ РФ, а при недоступности Нацбанк Беларуси. Обновляется при открытии, раз в 30 минут, при возврате на вкладку и при появлении сети.
Данные запоминаются в браузере: значения полей и выбранная валюта.
Адаптивная вёрстка. На телефоне итоговая цена закреплена внизу экрана.
Фоновое видео с кнопкой включения и выключения.
Экран загрузки: принтер Bambu Lab A1 с AMS «печатает» страницу при переходе.
 Оформление
Тёмная тема с оранжевым акцентом, панели «слоями» как у напечатанной детали.
Блок результатов в виде рабочей пластины принтера: сетка и угловые метки.
Моноширинные цифры, которые «печатаются» снизу вверх при изменении. Анимация отключается при включённом в системе «уменьшить движение».
Линейные SVG-иконки без внешних библиотек.
 Как считается цена
Статья	Формула
Материал	цена катушки ÷ вес катушки × расход материала × кол-во
Электроэнергия	время печати × мощность принтера × цена кВт·ч × кол-во
Печать	время печати × ставка печати × кол-во
Постобработка	время постобработки × ставка × кол-во
Моделирование	время моделирования × ставка (один раз на заказ)
Доставка	одна на весь заказ
Допматериалы	стоимость × кол-во
Цена детали	сумма всех статей

Числа можно вводить через точку или запятую.

 Запуск

Локально

Скачайте репозиторий.
Откройте index.html в браузере. Для фонового видео положите рядом video.mp4.
Прямая ссылка на калькулятор: index.html#calc.

На GitHub Pages

В репозитории откройте Settings → Pages.
В разделе Build and deployment выберите Deploy from a branch, ветку main и папку / (root).
Через минуту сайт откроется по адресу https://<75cmex75>.github.io/<репозиторий>/.

Для курса валют нужен интернет. Без сети используется последний сохранённый или примерный курс.

 Что хранится в браузере
Ключ localStorage	Содержимое
calc_state	значения полей и валюта
cur	выбранная валюта
bgVideo	включено ли фоновое видео

Данные привязаны к браузеру и адресу страницы. Очистка данных сайта их сотрёт.

Скрипты внутри index.html: расчёт и валюты, фоновое видео, навигация с экраном загрузки.
